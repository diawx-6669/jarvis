# 📱 Управление телефоном

Прямого "как на Маке" доступа к телефону нет — но есть рабочие способы.

## Если iPhone (проще всего)
Используй **Apple Shortcuts (Ярлыки)**:
1. На Маке и iPhone войди в один Apple ID (iCloud).
2. В приложении "Ярлыки" на Маке создай Automation, которая срабатывает,
   когда Jarvis выполняет osascript-команду `open location "shortcuts://run-shortcut?name=..."`.
3. Можно наоборот: с iPhone голосом через Siri вызывать ярлык, который
   через SSH/API стучится в твой Mac и просит Jarvis что-то сделать.

Practical пример: Jarvis на Маке может послать команду "включить будильник на
телефоне" через Shortcut, синхронизированный по iCloud между устройствами.

## Если Android
Через приложение **Tasker** + HTTP Server плагин:
1. На телефоне ставишь Tasker, поднимаешь локальный HTTP-сервер задач.
2. Jarvis на Маке (Python `requests`) стучится на IP телефона в локальной сети
   и вызывает задачу Tasker (например "включить фонарик", "отправить SMS").

## Важно
Это отдельная от Mac-ассистента настройка на каждом телефоне. Не "из коробки".
Рекомендую сначала обкатать Jarvis на Маке, а телефон подключать вторым этапом.
