# 📦 Как раздать Jarvis другим людям

Сейчас проект запускается через терминал (`python main.py`). Чтобы дать его
другим людям как нормальное приложение, есть два пути:

## Вариант 1 (просто): раздать как есть
Отправляешь им zip с проектом (как этот), они:
```
./scripts/install.sh
python main.py
```
Работает, но требует от них базовых навыков терминала и своего ключа Picovoice.

## Вариант 2 (сложнее, но "по-настоящему"): собрать .app
1. Используй `py2app` или `PyInstaller`, чтобы собрать `main.py` в `Jarvis.app`.
   ```
   pip install pyinstaller
   pyinstaller --windowed --name Jarvis main.py
   ```
2. Каждому пользователю всё равно понадобится СВОЙ Picovoice ключ (бесплатный,
   но нужна регистрация) — это ограничение бесплатного tier сервиса.
3. Чтобы .app запускался у других без предупреждений Gatekeeper ("приложение
   от неизвестного разработчика"), нужен Apple Developer аккаунт ($99/год) для
   подписи (code signing) и нотаризации.
4. Без подписи люди всё равно смогут запустить, но им придётся зайти в
   System Settings -> Privacy & Security и разрешить запуск вручную.

## Рекомендация
Начни с Варианта 1 для друзей/тестеров. Вариант 2 имеет смысл, если
хочешь распространять массово (App Store или сайт).
