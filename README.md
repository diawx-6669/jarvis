# 🤖 Jarvis — голосовой ассистент для Mac (Apple Silicon)

Локальный голосовой ассистент вроде "Jarvis" из Iron Man: постоянно слушает
wake word **"Hey Jarvis"**, распознаёт команду, выполняет её на Mac и отвечает голосом.

Работает полностью бесплатно и без регистрации — распознавание wake word
через открытую библиотеку [openWakeWord](https://github.com/dscripka/openWakeWord),
не через платные/ограниченные сервисы.

## Возможности (MVP)
- 🎙️ Постоянно слушает, активируется по фразе **"Hey Jarvis"**
- 🗣️ Понимает голосовые команды на русском и английском
- 💻 Управляет Mac: открывает сайты, приложения, ищет в Google, регулирует громкость
- 🔊 Отвечает голосом через встроенный `say` (macOS)
- 📁 Легко расширяется новыми командами (папка `commands/`)

## Структура проекта ("отделы")

```
jarvis-assistant/
├── voice/          # запись звука, wake word, распознавание речи (STT), синтез речи (TTS)
├── brain/          # логика: разбор команды -> что делать
├── commands/        # исполнители команд (открыть сайт, приложение и т.д.)
├── config/          # настройки, API-ключи (НЕ коммитить .env!)
├── scripts/         # установка, запуск, автозапуск
├── docs/            # документация
├── main.py          # точка входа
└── requirements.txt
```

## Быстрый старт (Mac, Apple Silicon)

```bash
cd jarvis-assistant
chmod +x scripts/install.sh
./scripts/install.sh
```

Скрипт установит все зависимости. Регистрация и ключи НЕ нужны.

Затем запусти:

```bash
source venv/bin/activate
python main.py
```

Скажи **"Hey Jarvis"** — услышишь "Да?" — скажи команду, например:
- "открой гугл"
- "открой сафари"
- "найди в гугле погоду в Астане"
- "какая громкость" / "сделай громкость 50"
- "открой заметки"
