# Что исправлено

## 1. "Bad Request" / тебя не слышит
`voice/listen.py` больше не ходит в бесплатный неофициальный Google-эндпоинт
(`recognize_google`) — именно он падал с Bad Request. Теперь распознавание
идёт **локально** через `faster-whisper` (офлайн, без интернета, точнее
понимает русский).

## 2. Окно интерфейса не появлялось
В `ui/gui.py` окно теперь принудительно выводится на передний план
(`lift()` + `focus_force()` + AppleScript-активация процесса). Раньше окно,
скорее всего, рисовалось, но пряталось за терминалом.

## 3. Голос
`voice/speak.py` теперь использует Microsoft Edge Neural TTS вместо
системного `say` — заметно живее и глубже. Голос актёра из фильма
("оригинальный Джарвис") я не клонирую — это чужая узнаваемая роль,
но подобрал похожий по духу тембр (глубокий, спокойный, без Google-акцента).
Хочешь ещё ближе к "живому" голосу — есть платные варианты (ElevenLabs,
Hume AI из твоего видео) с заметно более естественной интонацией, могу
подключить, если скажешь.

# Как обновить у себя

```bash
cd jarvis-assistant
source venv/bin/activate
pip install -r requirements.txt   # подтянет faster-whisper и edge-tts
python main.py
```

При самом первом запуске faster-whisper скачает модель распознавания
(~150 МБ, один раз, дальше офлайн).

# Если окно всё равно не видно
1. Посмотри в Dock — не появилась ли там иконка Python/ракета, кликни по ней.
2. Проверь Mission Control (F3) — не открылось ли окно на другом рабочем столе.
3. Быстрый тест, что tkinter вообще работает у тебя:
   `python3 -c "import tkinter; r=tkinter.Tk(); r.after(2000, r.destroy); r.mainloop()"`
   — если и тут ничего не появится 2 секунды, значит проблема в самой сборке
   Python (venv), и лучше переустановить Python с python.org (там tkinter
   собран корректно для GUI).
